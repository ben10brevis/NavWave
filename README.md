# NavWave – an unofficial client of LastWave

A sleek, open‑source Android client for the LastWave music streaming service.  It provides a modern glass‑morphism UI and the full set of playback features.

---

## 📱 Install

Download the debug APK from the repository artifacts:
- [`NavWave-debug.apk`](file:///C:/Users/Bala/.gemini/antigravity/brain/9682d94b-4b00-4ff0-a94f-9209c23a51ec/NavWave-debug.apk)
- [`NavWave-ClearLiquidGlass-debug.apk`](file:///C:/Users/Bala/.gemini/antigravity/brain/9682d94b-4b00-4ff0-a94f-9209c23a51ec/NavWave-ClearLiquidGlass-debug.apk)

Transfer the APK to your Android device, enable **"Install unknown apps"** if needed, and install.
